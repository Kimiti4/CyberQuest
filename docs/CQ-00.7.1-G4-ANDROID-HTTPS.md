## 1. Objective

Demonstrate that the Android debug client can reach the same server-authoritative demo API over a trusted HTTPS endpoint on a physical device, retrieve the mission, submit an assessment, receive the server-determined result with educational guidance, and fail safely on network or server errors.

## 3. What was implemented before any endpoint was exposed

### 3.1 Temporary exposure gateway — `src/cyberquest/g4_gateway.py`

Vendor-neutral ASGI reverse proxy. Controls, each pinned by a test in `tests/test_g4_gateway.py` (16 tests):

| Control | Implementation | Test |
|---|---|---|
| Route allowlist | Only `GET /v1/demo/missions/phishing-detective` and `POST /v1/demo/missions/phishing-detective/assessment` are forwarded | `test_allowed_mission_route_is_forwarded`, `test_allowed_assessment_route_is_forwarded_with_learner_choices_only` |
| Unknown route rejection | `404 not_found`; `/health/live`, `/docs`, `/redoc`, `/openapi.json` never reach upstream | `test_unknown_route_is_rejected_without_reaching_upstream`, `test_interactive_documentation_routes_are_rejected` |
| Method rejection | `405 method_not_allowed` with an `Allow` header for allowlisted paths; `DELETE`/`PUT`/`PATCH` rejected | `test_unsupported_method_on_allowed_path_is_rejected`, `test_delete_and_put_are_rejected` |
| Request body limit | 16 KiB default, enforced before forwarding; upstream is not called when exceeded | `test_oversized_body_is_rejected_before_reaching_upstream`, `test_default_body_limit_is_sixteen_kibibytes`, `test_body_at_the_limit_is_accepted` |
| Rate limiting | Separate GET (60/min) and POST (10/min) sliding windows per source address; `429` with `Retry-After` | `test_post_rate_limit_is_enforced`, `test_get_and_post_rate_limits_are_separate` |
| Upstream failure handling | `502 upstream_unavailable`, `504 upstream_timeout`; upstream 5xx relayed, never masked as success | `test_upstream_connection_failure_is_reported_as_gateway_error`, `test_upstream_timeout_is_reported_as_gateway_timeout`, `test_upstream_error_status_is_relayed_and_not_masked_as_success` |
| Identity stripping | `Authorization`, `Cookie`, `X-Api-Key` and forwarding headers are never passed upstream | `test_authorization_and_identity_headers_are_not_forwarded` |
| Minimal logging | Method, path, status, duration and outcome category only — no bodies, no headers, no client address | `test_logs_contain_no_payload_content_or_client_address` |
| No arbitrary egress | The upstream origin is a single configured URL; the CLI refuses to start against a non-loopback origin | `cyberquest.g4_gateway.main` |

### 3.2 External endpoint verification — `scripts/verify_g4_endpoint.py`

Runs the approved acceptance checks against any temporary HTTPS endpoint from outside the development machine: HTTPS-only, TLS chain and hostname validation, invalid hostname rejection, cleartext fallback rejection, mission retrieval, valid and incorrect assessments, unknown route rejection, unsupported method rejection, oversized body rejection and rate-limit throttling. Writes a machine-readable report; exits non-zero on any failure.

### 3.3 Android client controls

| Requirement | Implementation |
|---|---|
| HTTPS mandatory | Build fails on a non-HTTPS `CYBERQUEST_DEMO_API_BASE_URL`; the client refuses to call a non-HTTPS URL at run time |
| No cleartext fallback | `android:usesCleartextTraffic="false"` (unchanged) and the build/run-time guards above |
| No trust-all, no hostname bypass, no pinning | Verified by contract test scanning the client source for `X509TrustManager`, `HostnameVerifier`, `checkServerTrusted`, `setHostnameVerifier`, `TrustAll`, `CertificatePinner` |
| Explicit timeouts | 5 s connect, 5 s read (unchanged, now pinned by contract test) |
| Safe failure states | Mission load failure shows a message and a retry affordance; assessment failure shows an error without automatic resubmission |
| No duplicate/misleading submissions | The assessment POST is never retried automatically; resubmission requires an explicit user action against a stateless API |
| Educational guidance | The client now renders the server's per-indicator `guidance` field, so Android and web show the same teaching content |
| Build-time endpoint configuration | `-PCYBERQUEST_DEMO_API_BASE_URL=<https-url>`; the default remains a non-functional placeholder and no temporary endpoint is committed |
