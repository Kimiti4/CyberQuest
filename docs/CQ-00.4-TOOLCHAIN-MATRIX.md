## Selection guardrails

- Select Android plugin versions as a compatible tuple from official Kotlin, AGP and Gradle matrices; do not independently choose newest versions.
- Select a supported Node LTS line meeting the Next.js minimum. Pin exact patch and package manager when the web scaffold is created.
- Commit Gradle wrapper scripts/JAR and distribution checksum; enable dependency verification/locking.
- Commit one web package-manager lockfile and use immutable install (npm ci if npm is selected).
- Pin Android SDK/API/build tools and emulator image for CI.
- A toolchain is verified only after clean build and tests execute; a version matrix alone is not a build result.
