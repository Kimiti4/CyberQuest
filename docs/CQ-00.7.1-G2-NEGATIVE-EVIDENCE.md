## Defect found and corrected

**Defect:** An oversized request body was accepted through JSON parsing, returned `422`, and echoed the submitted input in the validation response. A 5 MB request produced a 5,000,114-byte response, creating unnecessary parsing and response-amplification exposure.

**Correction:** Added an ASGI `RequestBodyLimitMiddleware` with a 64 KiB limit. It rejects oversized `Content-Length` before route parsing and also counts streamed request chunks. Oversized requests now return `413` with `{"detail":{"code":"request_too_large"}}`.

**Regression coverage:** Added tests for forged score/mastery/competency/persistence fields, incomplete submissions, malformed JSON, and oversized-body rejection without payload echo.
