## Defect record (failed gate → documented defect → fix)

- **Failure:** `cross-platform-foundation-ci` run `43657976777` on `f828c8d` — Web clean install failed: `npm ci` → `EUSAGE` → `Missing: ajv@8.20.0 from lock file`.
- **Root cause:** the initial lock regeneration used `--legacy-peer-deps`, which dropped the auto-installed peer `ajv@8.20.0` (non-optional peer `ajv: 4.11.8 - 8` of `better-ajv-errors`, dev-only). CI runs plain `npm ci --no-audit --no-fund` (pinned npm `11.19.1`), which requires the peer present in the lock. Local verification on the same broken lock masked the failure because `node_modules` was already installed and `npm install` did not re-add the dropped entry.
- **Detection gap acknowledged:** verifying `npm run build`/`npm test` with a warm `node_modules` is insufficient; the gate must be validated with a clean `npm ci`.
- **Fix:** removed `node_modules`, regenerated the lock under default peer resolution; `node_modules/ajv@8.20.0` restored as `dev`, `peer: true` (identical entry to the pre-upgrade committed lock). Local `npm ci --no-audit --no-fund` now passes.
- **Remediation verification:** local `npm ci` clean install passes; typecheck, 12/12 contract tests, production build, redocly lint and `npm audit` re-verified; exact-head CI green on `e046199`.
