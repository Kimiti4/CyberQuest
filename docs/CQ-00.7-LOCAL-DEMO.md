# Running the CQ-00.7 Local Demo

**Status:** development instructions only. No hosted environment is provided by this checkpoint.

## 1. Start the FastAPI service

From the repository root, using the pinned Python environment:

```bash
python -m pip install --require-hashes -r requirements-lock.txt
PYTHONPATH=src python -m uvicorn cyberquest.main:app --host 127.0.0.1 --port 8000
```

Check:
- `GET http://127.0.0.1:8000/health/live`
- `GET http://127.0.0.1:8000/v1/demo/missions/phishing-detective`

The assessment route is:
- `POST http://127.0.0.1:8000/v1/demo/missions/phishing-detective/assessment`

Example body:

```json
{
  "selected_indicator_ids": ["sender_domain", "reply_to_mismatch"],
  "response_id": "verify_and_report"
}
```

The API returns deterministic feedback. It does not save attempts or award XP/competencies.

## 2. Start the web client

In another terminal:

```bash
cd web
npm ci
CYBERQUEST_API_BASE_URL=http://127.0.0.1:8000 npm run dev
```

Open the local Next.js development URL shown by the command. The browser calls same-origin Next.js routes; the server-side route proxies to FastAPI.

## 3. Build the Android demo

A device build needs an HTTPS API endpoint reachable from the phone and trusted by Android's system certificate store. The Android app disables cleartext HTTP; do not weaken this control to make a local network URL work.

```bash
cd android
./gradlew -PCYBERQUEST_DEMO_API_BASE_URL=https://your-trusted-development-api.example assembleDebug
```

The default API base URL is `https://127.0.0.1:8000`, which is a safe placeholder, not a reachable phone-hosted backend. A trusted HTTPS development endpoint or an explicitly configured local TLS setup is required for live Android integration.

## 4. Obtain the CI debug APK

After the Android CI job succeeds on the CQ-00.7 pull request, open that GitHub Actions run and download the `cyberquest-cq-00-7-debug-apk` artifact. It is a short-lived (7-day) unsigned/debug build for founder testing only, not a release APK. Install it with `adb install -r app-debug.apk`. The artifact uses the default API URL placeholder, so it is suitable for startup/layout inspection but will not connect to a laptop-hosted API without a new build configured for a reachable trusted HTTPS endpoint.

## 5. Scope and safety

- Do not expose the unauthenticated demo endpoints to the public internet.
- Do not use real phishing emails, addresses, attachments, credentials or external targets.
- The demo has no user accounts, saved history, XP, mastery or competency awards.
- A local demo result is not evidence of production security, legal compliance or actual phishing detection.
